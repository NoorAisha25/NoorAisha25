# Featured Projects

## KaamPaas — Hyperlocal Hiring Platform

A full-stack platform designed to connect workers with nearby job opportunities.

**Tech Stack:**  
`React.js` `Node.js` `Express.js` `MongoDB` `JWT` `Cloudinary` `Vercel` `Render`

### Key Engineering Work

- **Voice-First Job Discovery** — Voice-based job search using the Web Speech API with support for spoken commands and numbers across 5 Indian languages.
- **Geospatial Matching** — Matches workers to jobs within a 10 km radius using MongoDB 2dsphere indexing and `$near` queries.
- **Trust-Score Ranking** — Dynamically ranks candidates using rating average, completion rate, and verification bonus.
- **Multi-Role Communication** — Integrated CDN, OpenStreetMap Nominatim autocomplete, and WhatsApp API for communication.
